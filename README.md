# milkcord

Messenger with chats, posts, friends, calls, stickers and music.

## Repositories

- [milkcord-backend](https://github.com/BraveTonni/milkcord-backend) — FastAPI and Postgres: REST API, WebSocket events, file storage
- [milkcord-frontend](https://github.com/BraveTonni/milkcord-frontend) — React 19, MUI, Tailwind CSS
